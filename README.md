# BambooKit Web

The public website for BambooKit: landing page, install instructions, documentation and shared-session pages.

| Route | Content |
|---|---|
| `/` | Landing page and install command |
| `/docs/*` | Documentation (`src/content/docs.ts`) |
| `/share/:id` | A shared session, rendered from `bambookit-api` |
| `/install.ps1` | One-line Windows installer (`public/install.ps1`) |
| `/security`, `/privacy`, `/terms` | Policies |

## Develop

```powershell
npm install
copy .env.example .env.local     # set BAMBOOKIT_API_URL
npm run dev                      # http://localhost:3000
npm run build; npm start         # production
```

Brand assets in `public/` are generated by `bambookit-docs/brand/build_brand.py`. Palette: `#121212` and `#E5EDD5`.

Deployed on Render: set `BAMBOOKIT_API_URL` to the hosted API, and set `PUBLIC_SHARE_BASE_URL` on the API to this site's URL so share links point here.
