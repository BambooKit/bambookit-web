# BambooKit Web

The BambooKit website: landing page, install instructions, docs, sign-in, a view-only window on your PCs and sessions, and the public share viewer. It is a **static site** (Next.js `output: "export"`); everything signed-in runs in the browser and talks to `bambookit-api`.

| Route | Content |
|---|---|
| `/` | Landing page and install command |
| `/docs/*` | Documentation (`src/content/docs.ts`) |
| `/signin`, `/signup`, `/forgot`, `/reset` | Supabase email/password sign-in (plus Google when Firebase is configured) |
| `/welcome` | Onboarding: install Desktop, sign in on the PC, pair the phone |
| `/sessions` | PCs and all sessions, live |
| `/session/?id=<id>` | One session: chat and changed files, read live from the PC (view only) |
| `/devices`, `/approvals` | Devices and pending approvals (view only) |
| `/share/<id>` | A shared session (Render rewrites `/share/*` to `/share/index.html`) |
| `/install.ps1` | One-line Windows installer (`public/install.ps1`) |
| `/security`, `/privacy`, `/terms` | Policies |

## Configuration

All configuration is public and read at **build time** (`NEXT_PUBLIC_*`, see `.env.example`):

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_API_URL` | API origin. Default `http://localhost:8080` in dev, `https://bambookit-api.onrender.com` in production |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase publishable key (`NEXT_PUBLIC_SUPABASE_ANON_KEY` also accepted) |
| `NEXT_PUBLIC_FIREBASE_API_KEY`, `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`, `NEXT_PUBLIC_FIREBASE_PROJECT_ID` | Optional; all three enable the Google button |

Without the Supabase values the sign-in pages show "Sign-in is not configured on this deployment".

The API must allow this site's origin in `CORS_ORIGINS` (e.g. `https://bambookit-web.onrender.com,http://localhost:3000`).

## Develop

```powershell
npm install
copy .env.example .env.local     # fill in the Supabase values
npm run dev                      # http://localhost:3000
npm run typecheck
npm run build                    # static site in ./out
npx serve out                    # preview the export (optional)
```

In `next dev`, open shared sessions as `/share/?id=<id>`; the `/share/<id>` form needs the host rewrite.

## Deploy (Render Static Site)

`render.yaml` describes the site. With a Blueprint:

1. Render → **New → Blueprint** → pick this repository.
2. Set `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` when asked (and the Firebase values if you want Google sign-in).
3. Render runs `npm ci && npm run build` and publishes `./out`, with the `/share/*` rewrite and security headers from `render.yaml`.

Manually: **New → Static Site**, build command `npm ci && npm run build`, publish directory `out`, the environment variables above, and a rewrite rule `/share/*` → `/share/index.html`.

Because the configuration is baked in at build time, redeploy after changing an environment variable.

Set `PUBLIC_SHARE_BASE_URL` on the API to this site's URL so share links point here.

Brand assets in `public/` are generated by `bambookit-docs/brand/build_brand.py`. Palette: `#121212` and `#E5EDD5`.
